# CuraDoc Workspace Rules

## Mandatory Feature Documentation Rule
Whenever a new requirement, feature, domain entity, API endpoint, or UI flow is requested and implemented in the CuraDoc project:
1. You **MUST** update [`FEATURES.md`](./FEATURES.md) in the root of the repository before concluding the task.
2. Document all newly added or modified:
   - Domain entities and validation rules
   - Backend API endpoints and authorization constraints
   - Frontend routes, pages, and components
3. Keep [`FEATURES.md`](./FEATURES.md) accurate, structured, and synchronized with the codebase at all times.
