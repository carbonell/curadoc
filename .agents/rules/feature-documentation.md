# Feature Documentation Rule

For every new requirement, feature, or architectural change requested on the CuraDoc project:
1. After implementing and verifying the code changes, you **MUST** document the new functionality in `FEATURES.md` at the repository root.
2. Include details on any new or updated domain entities, backend API endpoints, authorization rules, and frontend pages/components.
